The Raspberry pi pico

The Raspberry Pi Pico is a low-cot microcontroller used to make electronic products.

The inputs and outputs I have used are:

input

  • Switch
  • Button
  • Potentiometer

output

  • LED
  • RGB LED
  • BUZZer
